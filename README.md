
Комплексное приложение для отслеживания сотрудников, проектов и их задач с финансовыми прогнозами.

 Функционал

 Управление данными
- Ежемесячные снимки состояния в localStorage
- Копирование данных между месяцами
- Полная изоляция исторических данных

 Сотрудники
- Ведение базы с должностями и зарплатами
- Календарь отпусков с расчетом рабочих дней
- Inline-редактирование позиции и зарплаты
- Назначение на проекты с гибким распределением (0.0-1.5)

Проекты
- Отслеживание бюджетов и требований к мощности
- Расчет выручки, затрат и прибыли
- Визуальная индикация перегрузки мощности

Финансовые расчеты
- Коэффициент отпуска: `(рабочие_дни - отпуск_рабочие) / рабочие_дни`
- Эффективная мощность: `capacity × fit × vacationCoefficient`
- Выручка: `budget / max(projectCapacity, usedEffective) × employeeEffective`
- Затраты: `salary × max(0.5, assignedCapacity)`

Фильтрация и сортировка
- Сортировка по клику на заголовки столбцов
- Фильтрация с чипами и быстрым сбросом
- Сохранение состояния при смене периода

Интерфейс
- Сворачиваемая боковая панель
- Всплывающие окна с авто-позиционированием
- Модальные окна с наложением
- Адаптивный дизайн

Технологический стек

- **HTML5** - семантическая разметка
- **CSS3** - Flexbox/Grid, CSS Variables
- **Vanilla JavaScript (ES6+)** - модульная архитектура
- **localStorage** - хранение данных
- **Без зависимостей** - 100% чистый код
